## 🚀 Featured Project

### [NetworkPolicy Intelligence System (NPI)](https://github.com/nassim-sai/netpol-intelligence)

A six-layer security observability platform for **OpenShift/Kubernetes**, built as my End-of-Study Engineering Project (PFE) at **NextStep IT**, in partnership with **TEK-UP University**.

Combines **OVN-Kubernetes flow analysis**, **statistical + ML anomaly detection** (Isolation Forest), an **8-rule NetworkPolicy compliance auditor**, and a **fully on-cluster LLM assistant** (Ollama/`llama3.2:3b`, zero data egress) into a live dashboard with real-time compliance scoring.
